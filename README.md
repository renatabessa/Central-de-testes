# Central de Testes Front-End 🚀

Este repositório é uma **coleção de mini projetos** desenvolvidos para praticar e testar conceitos de **JavaScript**.

## Projetos
A ideia é criar uma central onde cada link leva a um projeto independente, como:

- 🧮 Calculadora  
- 🧾 Extrato bancário  
- 🎲 Jogos simples  
- 🧰 Utilitários diversos  

## Objetivo
O projeto nasceu como um **laboratório de experimentação**: um espaço para consolidar fundamentos de front-end e testar ideias.  
Cada aplicação é pequena, mas focada em resolver um problema específico, permitindo testar lógica, manipulação de dados e boas práticas de código.

## Status
⚠️ **Em desenvolvimento**  
Este repositório está em constante evolução. Novos projetos e melhorias são adicionados regularmente, refletindo meu aprendizado contínuo

## Tecnologias
